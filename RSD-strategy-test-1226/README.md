
# ic_rsd_window

本プロジェクトは、**あなたの Config / ICConfig を完全に前提**として、
- 直前調整（Phase B）
- ショック

をすべて **OFF** にした上で、

> **初期配分（Window付きRSD）そのものに戦略的操作が存在するか**

を検証するための実験環境です。

## 実験内容

### 実験A
- 真の選好プロファイルを列挙（またはサンプル）
- 各エージェントについて
  - 正直申告
  - 許容される戦略（RESTRICTED）からの嘘申告
- Monte Carlo により期待効用を比較
- 嘘が有利なケースを保存

### 実験B
- 実験者が指定した1プロファイルを固定
- 正直 vs 嘘で
  - 各期
  - 各ウィンドウ
  - 各意思決定
を詳細ログとして出力し、
**なぜ戦略操作が有効になるのか**を分析可能

## 実行
```bash
python main_exp_a.py
python main_exp_b.py
```
